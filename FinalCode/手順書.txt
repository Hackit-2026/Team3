====================================================================
 機密情報保護カメラ「カクカク」（React + FastAPI 版）手順書
====================================================================

■ これは何か
  写真に写った「顔」と「文字列（個人情報・機密情報）」を自動検出し、
  モザイクをかけて保護するアプリです。

    ・フロントエンド … React製の画面（このフォルダ直下）
    ・バックエンド   … FastAPI製の検出API（backend フォルダ）

  顔・文字列の検出だけをバックエンドが行い、実際のモザイク描画は
  ブラウザ側（Canvas）で行います。設定を変えるたびにサーバーへ
  問い合わせ直さなくても、見た目の調整はブラウザ内で完結します。


--------------------------------------------------------------------
 1. フォルダ構成
--------------------------------------------------------------------
  FinalCode\
    ├ backend\             バックエンド（FastAPI）
    │   ├ main.py            APIエンドポイント一式
    │   ├ face_engine.py      顔検出・ホワイトリスト照合ロジック
    │   ├ llm_classifier.py   文字列の公開/非公開判定（ローカルLLM連携）
    │   ├ requirements.txt    Python依存パッケージ一覧
    │   ├ .env.example        環境変数のひな形（.envにコピーして使う）
    │   ├ mp_models\          （初回起動時に自動生成・ダウンロード）
    │   └ whitelist_store.pkl （初回登録時に自動生成）
    ├ src\                  フロントエンド（React）のソースコード
    ├ public\icon.png       アプリのアイコン
    ├ package.json / vite.config.ts / tsconfig*.json など
    └ 手順書.txt            （このファイル）


--------------------------------------------------------------------
 2. 初回だけ行う準備
--------------------------------------------------------------------
  必要なもの:
    ・Node.js 18以上
    ・Python 3.11〜3.13程度（mediapipe / paddleocr が対応するバージョン）
    ・Git

  (1) バックエンドの準備
        cd FinalCode\backend
        python -m venv venv
        venv\Scripts\activate
        pip install -r requirements.txt

      ローカルLLMによる文字列の公開/非公開判定を使う場合のみ、
      .env.example を .env にコピーして LOCAL_LLM_BASE_URL 等を設定します。
      未設定でも動きます。その場合は「判定できない＝安全側」に倒れ、
      検出した文字列はすべて private（モザイクON）扱いになります。

  (2) フロントエンドの準備
        cd FinalCode
        npm install

  (3) 顔検出モデルについて
      初回に顔検出処理を実行したタイミングで、以下のモデルファイルを
      自動でダウンロードします（backend\mp_models\ に保存）。
        ・face_landmarker.task
        ・blaze_face_full_range.tflite
        ・mobilenet_v3_small.tflite
      このときだけインターネット接続が必要です。以降はキャッシュされます。


--------------------------------------------------------------------
 3. 起動のしかた
--------------------------------------------------------------------
  ターミナルを2つ開いて、それぞれで実行します。

    1つ目（バックエンド）:
        cd FinalCode\backend
        venv\Scripts\activate
        python -m uvicorn main:app --host 127.0.0.1 --port 8000

    2つ目（フロントエンド）:
        cd FinalCode
        npm run dev

  フロントエンドは既定で http://localhost:8000 のバックエンドを見に
  行きます。バックエンドを別のホスト/ポートで動かす場合は、
  FinalCode 直下に .env.local を作り
        VITE_API_BASE_URL=http://<ホスト>:<ポート>
  を設定してください。

  npm run dev が表示するURL（通常 http://localhost:5173）をブラウザで
  開けば使用できます。


--------------------------------------------------------------------
 4. 画面の使い方
--------------------------------------------------------------------
  ▼ 4-1. ホーム画面
    ・「使用するモザイク」で既定のモザイク種類を選択（処理画面で後から
      変更可能）
    ・「ホワイトリストを管理」でホワイトリスト画面へ
    ・「写真をアップロード」または右下のカメラボタンで撮影 → 処理画面へ

  ▼ 4-2. ホワイトリスト画面
    ・「ホワイトリストを有効化」のON/OFF（全体スイッチ）
    ・顔写真＋名前を入力して「追加」（最大人数の制限はありません）
    ・登録済みの顔にマウスを乗せると編集（鉛筆）・削除（ゴミ箱）ボタンが
      表示されます

  ▼ 4-3. 撮影画面
    ・カメラのプレビューを見ながら中央下の丸ボタンで撮影 → 処理画面へ

  ▼ 4-4. 処理画面
    上部の「設定を適用してプレビュー更新」を押すたびに、現在の設定で
    検出・モザイク描画をやり直します。

    「マスク・検出設定」パネル:
      ・検出モード … 顔＋文字列 / 顔のみ / 文字列のみ
      ・マスク対象 … すべて（登録者も含めて全員マスク）/
                     未登録の顔のみ（ホワイトリスト登録者は除外）
      ・顔検出の精度 … 標準 / 高精度（人が多い・小さく写っている場合は
                     高精度を選択）

      ・顔のモザイク
          - モザイクの種類（ピクセル/ぼかし/絵文字/塗りつぶし/タイル）
          - マスク対象パーツ（顔全体・目元・右目・左目・鼻・口元、複数選択可）
          - マスクの形状（長方形/円形/顔の輪郭に合わせる）
          - スタイル詳細設定（粗さ・色・絵文字などの調整）

      ・文字列のモザイク
          - 顔とは独立してモザイクの種類・スタイル詳細を設定可能

      ・ホワイトリスト対象者（プルダウン）
          - 登録済みの名前一覧をON/OFFで個別に切り替え可能
          - 「全員ON」「全員OFF」で一括切り替え
          - OFFにした人は、その処理では除外対象から外れます（＝マスクされます）

    「検出された文字列一覧」パネル:
      ・検出された文字列ごとにチェックボックスがあり、ON/OFFで
        モザイクの適用有無を手動で切り替えられます
        （初期状態はローカルLLMの判定結果に従います）

    右上の「保存」ボタンで、現在のプレビュー画像をPNGとしてダウンロード
    します。


--------------------------------------------------------------------
 5. 困ったときは
--------------------------------------------------------------------
  ・「モザイク処理に失敗しました」と出る
      → バックエンド（uvicorn）が起動しているか、ポート8000が使われて
        いないか確認してください。

  ・ホワイトリストの登録・削除が反映されない
      → 同様にバックエンドの起動状況を確認してください。

  ・顔がうまく検出されない
      → 「顔検出の精度」を「高精度」に変更して再実行してください。

  ・ポート8000や5173（Viteの開発サーバー）が既に使われている
      → 別のプロセスが使っています。終了してから起動し直してください。


--------------------------------------------------------------------
 6. 開発メモ（編集するときの注意）
--------------------------------------------------------------------
  ・backend\main.py と face_engine.py は座標（顔の位置・輪郭・文字列の
    位置）だけを返し、モザイクの実描画は行いません。実描画は
    src\mosaic.ts（Canvas 2D）が担当します。検出ロジックとモザイク
    描画ロジックが分離されているため、どちらかだけを変更しても
    もう片方に影響しません。

  ・backend\whitelist_store.pkl（登録者の顔特徴量・サムネイル）と
    backend\mp_models\（ダウンロードしたモデル）はgit管理外です。
    端末ごとに自動生成されます。
