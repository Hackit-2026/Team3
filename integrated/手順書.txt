====================================================================
 AI Privacy Masking Suite（顔モザイク＋文字モザイク 統合版）手順書
====================================================================

■ これは何か
  これまで別々に動かしていた 2 つのアプリを、1 つの画面から使えるように
  まとめたものです。

    ・顔モザイク  … Hackit\face\app.py           （そのまま実行）
    ・文字モザイク … Hackit\word\frontend + backend（そのまま表示・実行）

  中身のプログラムには一切手を加えていません。統合版は「2つの既存アプリを
  1画面に並べる入れ物」として動くだけなので、モザイクの精度や操作方法は
  今までと完全に同じです。


--------------------------------------------------------------------
 1. フォルダ構成
--------------------------------------------------------------------
  Hackit\
    ├ face\           ← 顔モザイク（変更なし）
    ├ word\           ← 文字モザイク（変更なし）
    ├ aiconnection\   ← LLM中継サーバー（変更なし・任意）
    └ integrated\     ← ★今回追加した統合用フォルダ
        ├ app.py              統合画面（Streamlit）
        ├ text_backend.py     文字モザイク用サーバー（既存API＋画面配信）
        ├ requirements.txt    必要パッケージ一覧
        ├ 初回セットアップ.bat
        ├ 起動.bat
        └ 手順書.txt          （このファイル）


--------------------------------------------------------------------
 2. 初回だけ行う準備
--------------------------------------------------------------------
  (1) Hackit フォルダは英語名のフォルダの中に置いてください。
      日本語のフォルダ名が経路に入るとエラーになることがあります。

  (2) integrated\初回セットアップ.bat をダブルクリックします。
      次の 3 つが自動で行われます。
        ・face\mp_models フォルダの作成と、顔検出モデル2つのコピー
          （face_landmarker.task / blaze_face_full_range.tflite）
        ・pip の更新
        ・必要パッケージ一式のインストール（数分〜十数分）

  (3) 「セットアップが完了しました。」と出たら Enter キーで閉じます。

  ※ 文字モザイクのAI判定（LLM）を使う場合のみ、
     word\backend\.env の LOCAL_LLM_BASE_URL を設定してください。
     未設定でも動きます。その場合は「判定できない＝安全側」に倒れ、
     検出した文字はすべて private（モザイクON）扱いになります。


--------------------------------------------------------------------
 3. 起動のしかた
--------------------------------------------------------------------
  integrated\起動.bat をダブルクリックするだけです。

  自動的に次の 2 つが立ち上がります。
    ① 別ウィンドウ「Text Backend (OCR API)」… 文字認識サーバー
    ② ブラウザに表示される統合画面           … http://localhost:8501

  ※ どちらの黒いウィンドウも、アプリを使っている間は閉じないでください。
  ※ 初回は OCR モデルの自動ダウンロードで数分かかります。その間に
     文字モザイクを開こうとすると「接続できません」と出ますが、
     ダウンロードが終わってから画面の「接続を再確認する」を押せば繋がります。
  ※ Streamlit を初めて使うPCでは、黒い画面に
       「Welcome to Streamlit!  ... Email:」
     と表示されて止まることがあります。これは Streamlit 本体の初回だけの
     案内です。何も入力せずに Enter キーを押せば先に進みます
     （元の face\起動.bat でも同じ表示が出ます）。

  （手動で起動したい場合）
     コマンドプロンプトを2つ開いて、それぞれで実行します。
       1つ目: cd Hackit\integrated
               python -m uvicorn text_backend:app --host 127.0.0.1 --port 8000
       2つ目: cd Hackit\integrated
               python -m streamlit run app.py


--------------------------------------------------------------------
 4. 画面の使い方
--------------------------------------------------------------------
  画面の一番上に「🙂 顔モザイク / 🔤 文字モザイク」の切り替えがあります。
  ここをクリックすると、使う機能が切り替わります。
  左側のサイドバーには、いま選んでいる機能の設定だけが表示されます。


  ▼ 4-1. 顔モザイク（操作は従来の app.py と全く同じ）

    ① 左サイドバーで設定を選ぶ
        ・検出モード       標準 / 高精度（集合写真）/ 限界突破（群衆）
        ・マスク対象       顔全体・目元・右目・左目・鼻・口元（複数可）
        ・マスクの形状     顔の形（輪郭に沿う）/ 四角
        ・マスキングスタイル ピクセルモザイク / ぼかし / 絵文字スタンプ /
                            塗りつぶし / タイル状モザイク
          （スタイルを選ぶと、粗さ・色・絵文字などの調整項目が下に出ます）

    ② （任意）「👤 ホワイトリスト」を開き、モザイクをかけたくない人を登録
        ・名前を入れ、「ファイルを選ぶ」または「カメラで撮影」で顔写真を指定
        ・「＋ この顔を登録する」を押す（最大5名・データはこのPC内だけに保存）
        ・登録した人の顔は、解析時に自動でモザイク対象から外れます

    ③ 「加工したい写真をアップロードしてください」に写真をドロップ

    ④ 「🚀 AIモザイク解析を開始」を押す
        → 「解析成功！ ○箇所をモザイク対象として検出しました。」と表示され、
          左に元画像・右にマスキング結果が並びます。
        → ホワイトリストで除外された数もここに出ます。
        → 顔が見つからないときは検出モードを「限界突破」に上げて再実行。

    ⑤ 結果を見ながら、サイドバーで粗さ・形状・絵文字などを微調整
        （調整するたびに右のプレビューが即座に更新されます）

    ⑥ 「✅ これで決定」を押す → 「💾 加工画像をダウンロード」で保存


  ▼ 4-2. 文字モザイク（操作は従来の index.html と全く同じ）

    ① 画面上部が「🟢 文字認識バックエンドに接続済みです。」であることを確認
        赤いエラーが出ている場合は、別ウィンドウのOCRサーバーの準備待ちです。
        少し待ってから「🔄 接続を再確認する」を押してください。

    ② 埋め込み画面の「ファイルを選択」から写真を選ぶ
        → 自動で送信され、「○件の文字候補を検出しました。」と表示されます。

    ③ モザイクの種類を選ぶ（黒塗り / ぼかし / ピクセル化）
        選び直すと、すでにかかっているモザイクも即座に切り替わります。

    ④ 下の「検出された文字列」一覧で、隠す・隠さないを調整
        ・private（赤）… 個人情報の可能性あり。最初からモザイクON
        ・public （緑）… 一般に公開されている情報とLLMが判断。最初からOFF
        ・チェックボックスを外すとモザイク解除、付けると再適用
        ・画像上の枠を直接クリックしても、同じように切り替えられます

    ⑤ 隠し足りない部分は、画像の上をドラッグすると手動で枠を追加できます
        （追加した枠は「(手動追加)」として一覧に並びます）

    ⑥ 「ダウンロード」ボタンで mosaic.png として保存

    ※ 縦長の写真で下が見切れる場合は、左サイドバーの
       「表示エリアの高さ (px)」を大きくしてください。


--------------------------------------------------------------------
 5. 困ったときは
--------------------------------------------------------------------
  ・文字モザイクが「接続できません」のまま
      → 別ウィンドウ「Text Backend (OCR API)」が閉じていないか確認。
        閉じていたら 起動.bat をもう一度実行してください。

  ・顔が検出されない
      → 検出モードを「限界突破（群衆・交差点）」に変更して再解析。
        それでも駄目な場合は、顔が画像全体の40%以上を占めていないか確認
        （大きすぎる枠は誤検知として除外される仕様です）。

  ・「mp_models フォルダがありません」と出る
      → 初回セットアップ.bat を実行し直してください。

  ・ポート8000や8501が既に使われている
      → 別のアプリが使っています。そちらを終了してから起動し直してください。

  ・元の単体アプリも今まで通り使えます
      （face\起動.bat、word の uvicorn 起動 のどちらも変更していません）

 6. 開発メモ（編集するときの注意）
--------------------------------------------------------------------
  ・integrated\起動.bat と 初回セットアップ.bat は Shift-JIS(cp932) で
    保存しています。UTF-8 で保存し直すと、日本語が増えたときに cmd.exe が
    ファイルの読み取り位置を見失い、行の途中から実行して壊れます
    （実際に UTF-8 版で「'p_models' は認識されていません」等のエラーを確認）。
    編集する場合は Shift-JIS のまま保存してください。
    メモ帳なら「ANSI」、VS Code なら右下の文字コードを「Shift JIS」にします。

  ・app.py は face\app.py を runpy でそのまま実行しています。
    face\app.py を書き換えれば、統合画面にもそのまま反映されます
    （コピーを持っていないので、二重管理になりません）。

  ・text_backend.py は word\backend\main.py の FastAPI アプリをそのまま
    読み込み、/ui のマウントを足しているだけです。
    word 側の API を書き換えれば、統合画面にもそのまま反映されます。
