====================================================================
 AI Privacy Masking Suite（顔＋文字 同時モザイク 統合版）手順書
====================================================================

■ これは何か
  これまで別々に動かしていた 2 つのアプリを、1 つの画面・1 回の操作で
  まとめて使えるようにしたものです。

    ・顔モザイク  … Hackit\face\app.py           （中身は変更なし）
    ・文字モザイク … Hackit\word\backend + frontend（判定ロジックは変更なし）

  写真を 1 枚アップロードして解析ボタンを押すと、顔と文字を「同時に」検出し、
  2 つの結果を合わせて 1 枚の画像にモザイクを掛けます。


--------------------------------------------------------------------
 1. フォルダ構成
--------------------------------------------------------------------
  Hackit\
    ├ face\           ← 顔モザイク（app.py は無改変のまま使用）
    ├ word\           ← 文字モザイク
    ├ aiconnection\   ← LLM中継サーバー（デスクトップ側で動かすもの）
    └ integrated\     ← ★統合用フォルダ
        ├ app.py              統合画面（Streamlit）
        ├ text_backend.py     文字認識サーバー（既存API＋画面配信）
        ├ requirements.txt    必要パッケージ一覧
        ├ 初回セットアップ.bat
        ├ 起動.bat
        └ 手順書.txt          （このファイル）


--------------------------------------------------------------------
 2. 初回だけ行う準備
--------------------------------------------------------------------
  (1) Hackit フォルダは英語名のフォルダの中に置いてください。
      日本語のフォルダ名が経路に入るとエラーになることがあります。

  (2) integrated\初回セットアップ.bat をダブルクリックします。
        ・face\mp_models の作成と顔検出モデル2つのコピー
        ・pip の更新
        ・必要パッケージ一式のインストール（数分〜十数分）
      が自動で行われます。

  (3) LLM判定を使う場合は word\backend\.env を編集します。

        LOCAL_LLM_BASE_URL=https://xxxx.trycloudflare.com

      ★重要★ 末尾に「/」を付けないでください。
        付けると送信先が「//api/check_mask」となり 404 になります。
        その場合エラーは出ませんが「判定不能＝全部モザイク」に倒れるため、
        LLM 判定だけが静かに効かなくなります。
        （現在は llm_classifier.py 側でも末尾の / を取り除くようにしています）

      .env を書き換えたら、サーバーの再起動が必要です
      （黒いウィンドウを閉じて 起動.bat をやり直す）。


--------------------------------------------------------------------
 3. 起動のしかた
--------------------------------------------------------------------
  integrated\起動.bat をダブルクリックするだけです。

  自動的に次の 2 つが立ち上がります。
    ① 別ウィンドウ「Text Backend (OCR API)」… 文字認識サーバー
    ② ブラウザに表示される統合画面           … http://localhost:8501

  ※ どちらの黒いウィンドウも、使っている間は閉じないでください。
  ※ 初回は OCR モデルの自動ダウンロードで数分かかります。
  ※ Streamlit を初めて使うPCでは「Welcome to Streamlit! … Email:」と出て
     止まることがあります。何も入力せず Enter を押せば進みます。


--------------------------------------------------------------------
 4. 使い方（顔と文字をまとめて処理する）
--------------------------------------------------------------------

  ▼ 手順1: 左サイドバーで設定を選ぶ

    【⚙️ マスク設定】＝顔むけ（従来と全く同じ項目）
      ・検出モード       標準 / 高精度（集合写真）/ 限界突破（群衆）
      ・マスク対象       顔全体・目元・右目・左目・鼻・口元（複数可）
      ・マスクの形状     顔の形（輪郭に沿う）/ 四角
      ・マスキングスタイル ピクセルモザイク / ぼかし / 絵文字スタンプ /
                          塗りつぶし / タイル状モザイク
        （選ぶと粗さ・色・絵文字などの調整項目が下に出ます）

    【🔤 文字モザイク設定】＝今回追加
      ・文字も検出してモザイクする
          外すと顔だけを処理します。文字認識サーバーが止まっていても
          使えるので、顔だけ急いで処理したいときに便利です。
      ・文字部分の塗りつぶし方
          「黒塗り」＝元の文字モザイクアプリと同じ見た目（既定）
          「顔と同じマスキングスタイル」＝顔と揃えたい場合
      ・public と判定された文字も隠す
          既定では public（一般公開情報）はモザイクしません。
      ・文字を手作業で編集する画面も開く
          元の文字モザイクアプリをそのまま下に埋め込みます。
          ドラッグで枠を足したいときだけONにしてください。

  ▼ 手順2:（任意）ホワイトリストに登録する
      「👤 ホワイトリスト」を開き、モザイクを掛けたくない人を登録します。
      名前を入れて写真を選び「＋ この顔を登録する」（最大5名）。
      登録した人の顔は、解析時に自動でモザイク対象から外れます。
      データはこのPC内にだけ保存されます。

  ▼ 手順3: 写真をアップロードする
      「加工したい写真をアップロードしてください」にドロップします。

  ▼ 手順4: 「🚀 顔と文字をまとめて解析」を押す
      顔検出と文字検出（OCR＋LLM判定）が続けて実行され、
      「解析完了！ 顔 ○ 箇所 ／ 文字 ○ 箇所を検出しました。」と出ます。
      左に元画像、右に「顔＋文字」をまとめてマスクした結果が並びます。
      かかった時間も下に表示されます（目安：写真1枚で 5〜10 秒程度）。

  ▼ 手順5: 結果を見ながら調整する
      ・サイドバーの粗さ・形状・絵文字などを変える
      ・「🔤 検出された文字列」の一覧でチェックを付け外しする
          🔴 private ＝個人情報の可能性あり（既定でON）
          🟢 public  ＝一般公開情報とLLMが判断（既定でOFF）
      どちらも 0.3 秒ほどで反映されます。
      調整のたびに検出をやり直すことはないので、待たされません。

  ▼ 手順6: 「✅ これで決定」→「💾 加工画像をダウンロード」で保存


--------------------------------------------------------------------
 5. 元の単体アプリについて
--------------------------------------------------------------------
  今まで通り、単体でも使えます。

    ・顔だけ  : face\起動.bat
    ・文字だけ: word\backend で uvicorn main:app を起動し、
                word\frontend\index.html をブラウザで開く
                （統合版の起動中なら http://localhost:8000/ui/index.html でも同じ）

  ドラッグでの枠追加や、画像上の枠を直接クリックしての解除は、
  元の文字モザイクアプリだけが持つ機能です。統合画面からも
  サイドバーの「文字を手作業で編集する画面も開く」で呼び出せます。


--------------------------------------------------------------------
 6. 困ったときは
--------------------------------------------------------------------
  ・文字が1つも検出されない／サーバーに繋がらない
      → 別ウィンドウ「Text Backend (OCR API)」が閉じていないか確認。
        閉じていたら 起動.bat をもう一度実行してください。
        サイドバーの「文字も検出してモザイクする」を外せば、
        顔だけは処理できます。

  ・文字が全部 private になる（public が1つも出ない）
      → LLM に繋がっていません。word\backend\.env の
        LOCAL_LLM_BASE_URL を確認してください（末尾の / は不要）。
        デスクトップ側の Ollama と cloudflared が動いているかも確認を。

  ・顔が検出されない
      → 検出モードを「限界突破（群衆・交差点）」に変更して再解析。
        顔が画像全体の40%以上を占めていると誤検知として除外されます。

  ・処理が遅い
      → 写真1枚あたり 5〜10 秒が目安です。極端に遅い場合は
        word\backend\main.py の text_detection_model_name /
        text_recognition_model_name の指定が消えていないか確認してください
        （指定が無いと重い PP-OCRv6_medium が使われ、3倍以上遅くなります）。

  ・ポート8000や8501が既に使われている
      → 別のアプリが使っています。そちらを終了してから起動し直してください。


--------------------------------------------------------------------
 7. 開発メモ（編集するときの注意）
--------------------------------------------------------------------
  ・integrated\起動.bat と 初回セットアップ.bat は Shift-JIS(cp932) で
    保存しています。UTF-8 で保存し直すと、日本語が増えたときに cmd.exe が
    ファイルの読み取り位置を見失い、行の途中から実行して壊れます。
    編集する場合は Shift-JIS のまま保存してください。
    メモ帳なら「ANSI」、VS Code なら右下の文字コードを「Shift JIS」に。

  ・integrated\app.py は face\app.py を「そのまま実行」して、
    サイドバーの設定UI・ホワイトリストUI・検出/マスク関数を借りています。
    face\app.py 側の「加工したい写真をアップロードしてください」という
    ラベルを目印に、そこで実行を打ち切っています。
    このラベルを変更する場合は、app.py の FACE_MAIN_UPLOADER_PREFIX も
    合わせて直してください（ズレると画面が二重になり、警告が出ます）。

  ・文字の矩形は text_to_mask_item() で顔側と同じ形に変換しているので、
    マスクの描画は face\app.py の apply_masking() が1つ担当しています。
    マスキング処理を増やしたい場合は face 側だけ直せば両方に効きます。

　・バックでローカルLLMが動いておりそこにgitに挙げているだけのものでは到達
　　できないのでgitからダウンロードして動作を確認できるものは顔認識機能全般
　　と文字認識をおこないすべての文字にモザイクを掛ける迄である。
