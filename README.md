# プロダクト名

機密情報保護カメラ「カクカク」

## 概要

撮影した写真を加工し、登録してある持ち主の顔以外をモザイクで隠すことが出来ます。
さらに文章に足してもOCRを用いて言葉を検知したのち、機密情報を隠せるようにしています。
また、文章に関してのみ隠した部分のモザイクを部分ごとに外すことも出来ます。

## 工夫した点・こだわった点

顔認識・モザイク処理では、読み込んだ画像をいくつかのグリッドに分割してスキャンし、AIへと渡します。その後、分割したグリッド内のどこに顔があるか判別しています。分割する際、顔が真っ二つになるなどの検出漏れを避けるため、30%のオーバーラップを持たせ切り出しています。
またさらに精度を上げるため、オーバーラップによる重複した顔枠のうち一番スコアが高いもののみ残すようにしています。
他にも、6ピクセル未満の極小ノイズや画面全体の40%を超える巨大すぎる枠などのルールを適用し即座に除外しています。
まず重い処理を行うのではなく、遠距離特化のモデルを使用し、その後顔の輪郭に沿ったマスクが必要な場合顔の部分だけを切り抜き詳細な座標を解析しています。
AIが出力した顔の枠は実際の顔よりも小さくなる可能性があります。そのため、検出された枠に対し幅や大きさを少し広げるように調整しています。
